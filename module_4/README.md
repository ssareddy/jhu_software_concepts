# Module 4 — Grad Café Analytics: Tests & Documentation

A test-driven, documented Grad Café data analytics service covering scraping,
ETL, PostgreSQL storage, and a Flask analysis dashboard.

## Setup

```bash
# 1. Install dependencies
pip install -r module_4/requirements.txt

# 2. Set up PostgreSQL
createdb gradcafe            # production DB
createdb gradcafe_test       # test DB

# 3. Set environment variable (or edit src/query_data.py DB_CONFIG)
export DATABASE_URL="postgresql://postgres:<password>@localhost:5432/gradcafe"
```

## Running Tests

```bash
# Full suite (all markers)
pytest module_4/tests -m "web or buttons or analysis or db or integration"

# By marker
pytest module_4/tests -m web
pytest module_4/tests -m buttons
pytest module_4/tests -m db
pytest module_4/tests -m analysis
pytest module_4/tests -m integration

# With coverage
pytest module_4/tests -m "web or buttons or analysis or db or integration" \
  --cov=module_4/src --cov-report=term-missing --cov-fail-under=100
```

### Test markers

| Marker | Description |
|---|---|
| `web` | Flask route/page rendering tests |
| `buttons` | Pull Data / Update Analysis button behavior & busy-state |
| `analysis` | Label presence and percentage formatting (two decimals) |
| `db` | Database schema, inserts, idempotency, query function |
| `integration` | End-to-end: pull → update → render flows |

### Test doubles / selectors

- **Scraper/loader**: injected via `create_app(loader_fn=...)` — no live network calls.
- **Query function**: injected via `create_app(query_fn=...)` — tests use a real test DB or a mock.
- **HTML selectors**: `data-testid="pull-data-btn"` and `data-testid="update-analysis-btn"`.
- **Busy state**: observable via `GET /api/scrape_status` — no `sleep()` in tests.

## GitHub Actions CI

Workflow: `.github/workflows/tests.yml`

The pipeline:
1. Starts a PostgreSQL 15 service container
2. Installs Python 3.11 + requirements
3. Runs the full pytest suite with 100% coverage enforcement
4. Saves the coverage summary to `module_4/coverage_summary.txt`
