# Module 12 — Two-Layer Neural Network for Graduate Admissions Prediction

## What the Program Does

`neural_network.py` implements a two-layer (one hidden layer) neural
network entirely from scratch using NumPy — no PyTorch, TensorFlow, Keras,
JAX, or scikit-learn neural network utilities are used anywhere in the
implementation. scikit-learn is used only for the train/test split.

The network predicts whether a graduate school applicant was **Accepted**
or **Rejected** based on six features: GPA, GRE (combined), GRE Verbal,
GRE Analytical Writing, degree type (Master's vs. PhD), and citizenship
(International vs. Local/American).

The script runs the full pipeline end to end:
1. Loads and filters the applicant dataset, engineers the six input
   features and the binary target
2. Splits into train/test (80/20), then fills missing values and
   standardizes features using training-set statistics only
3. Builds a 6-input, 6-hidden-unit, 1-output network with sigmoid
   activations, initialized from N(0, 0.1) weights and zero biases
4. Trains with full-batch gradient descent and MSE loss, using early
   stopping (patience = 100 epochs) on test-set MSE
5. Evaluates the best-performing model (by test MSE) and reports final
   metrics
6. Plots training/test MSE over epochs, saved as `mse_curve.png`
7. Runs the trained model on four manually specified artificial
   applicants and reports their predictions

## Where to Add the Data File

This assignment expects a JSON-Lines applicant dataset with one JSON
object per line, containing the fields `gpa`, `gre`, `gre_v`, `gre_aw`,
`masters_or_phd`, `citizenship`, and `applicant_status`.

Place your dataset file in this folder (the same directory as
`neural_network.py`) and either:

- name it `applicant_data.jsonl` (the default the script looks for), or
- pass its path explicitly with `--input <path-to-your-file>`

No dataset file is included in this submission — supply your own
JSON-Lines file matching the schema above before running the script.

## How to Run

```bash
pip install numpy pandas matplotlib scikit-learn
python neural_network.py --input applicant_data.jsonl --output-dir .
```

This prints all required output for every section directly to the
console (dataset filtering counts, split statistics, network parameter
shapes, training progress every 100 epochs, final evaluation, and the
artificial applicant table) and writes `mse_curve.png` to `--output-dir`.
A full run takes well under a minute.
